# APLICACION EMPLEADOS
Aplicacion para los empleados de los clubes para realizar el control de acceso de los socios, y para corroborar las reservas e inscripciones de los mismos

## Setup

```bash
npm install
cp .env.local.example .env.local   # completar con las credenciales de Firebase y la URL del gateway
npm run dev                        # http://localhost:5138
```
